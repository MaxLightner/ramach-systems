# کاتالوگ سرویس‌های AI و AEC: جهان و ایران

**تاریخ بررسی:** ۲۹ اکتبر ۲۰۲۶ — **مجموع: 59 عرضه‌کننده/محصول** (44 جهانی، 15 ایران).

این جدول به‌جای فهرست نام‌های «هوش مصنوعی»، مشخص می‌کند **هر عرضه‌کننده دقیقاً چه بخش از کار شرکت معماری، مهندسی، پیمانکاری یا مالک را انجام می‌دهد**. وجود یک شرکت در جدول به‌معنی تأیید کیفیت، وجود مشتری یا قابل‌استفاده بودن آن در ایران نیست.

## راهنمای «اتصال»
- **A — API/SDK یا رابط برنامه‌نویسی رسمی مستند**: ممکن است به حساب پولی/تأییدیه/نصب نرم‌افزار نیاز داشته باشد؛ مجوز embedded/white-label تضمین‌شده نیست.
- **B — افزونه، MCP، واردات/صادرات یا یکپارچه‌سازی رسمی**: اتصال واقعی ممکن است، اما API وب عمومی برای همان قابلیت در پژوهش تأیید نشده، یا محدود به لایسنس/نسخه است.
- **C — پنل/خدمت آماده**: API رسمیِ قابل استفاده در پژوهش تأیید نشد. **C به معنی نبود قطعی API نیست**.
- **D — توسعه سفارشی / راهکار سازمانی**: عرضه سرویس آماده و قابل ثبت‌نام عمومی احراز نشده است.

«AI» در جدول صرفاً برچسب نوع فناوری بر اساس توضیح رسمی سازنده است؛ هیچ تست مستقل دقت یا استقلال تصمیم‌گیری انجام نشده. اتصال وضعیت خود محصول است، نه تضمین حق فروش مجدد.

## برداشت‌های مقایسه‌ای
1. محصولاتی مانند **Forma / Snaptrude / Hypar** به بخش بالادستِ **طرح و مدل** نزدیک‌ترند؛ **Deltek / Monograph / BQE / Projectworks** به عملیات خود **شرکت مهندسی**؛ و **Procore / Archdesk / Buildots** به **پروژه در حال ساخت**.
2. **Kreo و SkyCiv** نمونه‌های مهم فناوری تخصصی با API مستند هستند: اولی نقشه دوبعدی را به کمیت/هندسه خواندنی تبدیل می‌کند، دومی تحلیل سازه و کنترل‌های مشخص را اجرا می‌کند؛ اتصال این دو جایگزین کنترل مهندس نمی‌شود.
3. در ایران، خدمات **متره، دفتر فنی، حسابداری پیمان و مدیریت کارگاه** دیده شد؛ برای **تولید BIM قابل‌استناد، محاسبه همه رشته‌ها و کنترل یکپارچه مقررات ملی با API عمومی** در این نمونه‌ها شواهد کافی پیدا نشد.
4. خطای رایج در مقایسه: رابط چت AI، یکپارچه‌سازی PDF، و حل‌گر استاندارد مهندسی سه قابلیت متفاوت‌اند؛ نباید همه را «طراحی کامل ساختمان با AI» نامید.

## محدودیت‌ها
- منابع، صفحات رسمی خود شرکت‌ها هستند؛ ادعاهای بازاریابی و اجرای واقعی ممکن است متفاوت باشند.
- API عمومی در ردیف A نیز لزوماً اجازه ساخت محصول تجاری جایگزین یا white-label را نمی‌دهد؛ باید شرایط هر شرکت خوانده شود.
- خدمات قانون/مجوز مانند UpCodes و PermitFlow بیشتر به آمریکا مربوط‌اند و ضوابط ایران را پوشش‌داده فرض نکنیم.
- ویژگی‌ها، قیمت‌ها و APIها سریع تغییر می‌کنند. قبل از خرید یا پیاده‌سازی، دموی عملی و استعلام مجوز لازم است.
- این یک **بازبینی مرحله اولِ گسترده** است، نه فهرست جامع تمام شرکت‌های جهان یا ارزیابی کامل امنیت/هزینه.
